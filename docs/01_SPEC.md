# BrandProfitFinder

## Project Goal

BrandProfitFinder is a Python application that discovers profitable luxury brand products by comparing prices between overseas retailers and Japanese marketplaces.

The system should:

- Collect products from supported overseas stores.
- Compare prices with Japanese marketplaces.
- Calculate expected profit.
- Export results to Excel.
- Be designed for AI-assisted development.

---

## Initial Supported Stores

- Cettire
- Baltini
- Italist

---

## Future Supported Stores

The architecture must support 30+ stores without major redesign.
