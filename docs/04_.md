# AI Development Rules

## General Rules

- Follow SPEC.md
- Follow ARCHITECTURE.md
- Follow TASK.md
- Keep modules small
- Write readable code
- Use type hints
- Add logging
- Handle exceptions

---

## File Rules

Never create duplicate files.

Do not rename files without reason.

Keep folder structure unchanged.

---

## Code Rules

Use Python 3.14.

PEP8 compliant.

One responsibility per class.

One responsibility per function.

Avoid duplicated logic.

---

## Commit Rules

Complete one task at a time.

Verify code before moving to the next task.

---

## AI Rules

When unsure,

choose the safest implementation.

Never delete working code.

Prefer extending existing modules.

Always explain major architectural changes.
