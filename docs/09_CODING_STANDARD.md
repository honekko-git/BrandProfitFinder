# Coding Standard

## Python

Python 3.14

PEP8

Type hints required

UTF-8

---

## Naming

Classes

PascalCase

Functions

snake_case

Variables

snake_case

Constants

UPPER_CASE

---

## Functions

Maximum 30 lines.

Single responsibility.

Always return explicit values.

---

## Classes

Maximum 200 lines.

One responsibility.

No God classes.

---

## Logging

Never use print().

Always use logging.

Log every exception.

---

## Error Handling

Catch expected exceptions.

Raise unexpected exceptions.

Never ignore exceptions.

---

## Documentation

Every public function must have docstrings.

Every module needs comments.

---

## Imports

Standard library

↓

Third-party

↓

Local modules

---

## Formatting

Black compatible.

No trailing whitespace.

One blank line between logical blocks.

---

## AI Rules

Do not rewrite working modules.

Prefer extension over replacement.

Keep compatibility.

Never duplicate code.
